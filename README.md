Отдельный аддон для Minecraft 1.21.1 / NeoForge 21.1.235 и MineColonies 1.1.1374-1.21.1-snapshot. 

## Скачать и установить

**[Скачать Colony Guard Posts 1.0.0](https://github.com/canibeaieng/Colony-Guard-Posts/raw/refs/heads/main/dist/colonyguardposts-1.0.0.jar)** · [SHA-256](dist/colonyguardposts-1.0.0.jar.sha256)

Поместить JAR в `mods` сборки с указанной версией MineColonies и перезапустить Minecraft. В сетевой игре аддон нужен на сервере и у игроков. Зависимости MineColonies должны быть установлены отдельно; в JAR аддона они не включены.

## Использование

1. Открыть **башню казармы**, выбрать задание **«Пост» / «Охранять»** и получить штатный скипетр стражника.
2. ПКМ скипетром по полу добавляет пост. Инструмент остаётся в руке; можно отметить до 16 точек. Зелёные частицы кратко показывают уже отмеченные посты.
3. Shift+ПКМ по отмеченному полу удаляет пост. Shift+ПКМ по блоку **той башни, к которой привязан скипетр**, очищает весь список и возвращает охрану к башне.

Стражники распределяются равномерно: пять бойцов на три поста — 2/2/1. Каждый сохраняет назначение, пока изменение состава или постов не требует перераспределения. Лишние точки остаются пустыми. Список и назначения сохраняются вместе с башней. После боя и обычных служебных дел стражник снова получает свой пост.

Режимы патруля/следования и обычные одиночные сторожевые башни используют штатное управление MineColonies. При переключении задания список постов сохраняется, но действует только в режиме охраны.

Пост требует твёрдой безопасной опоры и двух свободных блоков над ней, территории собственной колонии и допустимой дальности башни. К нему нужен проходимый маршрут: навигацией, боем, снабжением и лечением управляет MineColonies. Проверка места не доказывает проходимость всего пути. Заваленные/разрушенные посты временно исключаются из распределения; если доступных постов нет, используется позиция башни. Выгруженные точки сохраняют назначения; для них не загружаются новые чанки, до их загрузки стражник получает позицию башни.

## Реализация и совместимость

- Три mixin: индивидуальный `getGuardPos`, сохранение NBT и обработка штатного скипетра; точность подхода к включённым постам — 1 вместо штатных 5 блоков.
- Дополнительный NBT ключ `colonyguardposts:posts` имеет версию 1. Старые одиночные позиции и маршруты не мигрируются и остаются совместимыми.
- На сервере проверяются право `MANAGE_HUTS`, измерение, досягаемость клика, территория, дальность и ревизия списка. Устаревший скипетр обновляется без изменения постов; игрок повторяет действие.
- Назначения используют ID жителей внутри конкретной башни/колонии. Пересчёт не чаще раза в 20 тиков, сразу после редактирования — без ожидания. Выгруженные жители учитываются в составе.
- Нет новых сущностей, предметов, сетевых пакетов, chunk tickets, телепортаций или глобального сканирования мира. Аддон устанавливается на клиент и сервер; для одиночной игры достаточно одного JAR в `mods`.
- Версия зависимости MineColonies зафиксирована на проверенной сборке. При обновлении MineColonies требуется проверить сигнатуры mixin и тесты.

## Сборка и проверки

Требуется **JDK 21**. Указать путь к `minecolonies-1.1.1374-1.21.1-snapshot.jar` через переменную `MINECOLONIES_JAR`. Рядом должны находиться зависимости MineColonies. Проверенные версии:

- Structurize `1.0.832-1.21.1`;
- BlockUI `1.0.211-1.21.1-snapshot`;
- Domum Ornamentum `1.0.234-snapshot-main`;
- Multi-Piston `1.2.58-1.21.1`.

PowerShell:

```powershell
$env:MINECOLONIES_JAR = 'C:/path/to/mods/minecolonies-1.1.1374-1.21.1-snapshot.jar'
.\gradlew.bat build runGameTestServer --no-daemon
```

Linux/macOS:

```sh
export MINECOLONIES_JAR='/path/to/mods/minecolonies-1.1.1374-1.21.1-snapshot.jar'
./gradlew build runGameTestServer --no-daemon
```
